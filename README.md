## 構成の理由

試作ページのヘッダー・フッター・CTA から現行ページへ計239本のリンクが張られています。
サイト一式を `site/` 配下に置くことで、これらの相対リンクを1本も書き換えずに成立させています。
ルートの `index.html` は、このプレビューのために新規作成した入口ページです。

## 内容について

文言・数値・9職種・7名のインタビュー・求人条件・キャリアプラン・JSON-LD は、
現行サイトから変更していません。デザイン（レイアウト・配色・図解）のみが検証対象です。

プレビュー化にあたって加えた変更は次の3点のみです。

1. 入口ページ `index.html` の新規作成（リンク先を `site/` 配下へ）
2. リンク切れ2本の修正（`redesign/people/sales.html` と `system.html` の募集要項リンクのパス）
3. 試作ページ上部の告知バーの文言を「デザイン検証用プレビュー｜本番サイト未反映」に変更（34ファイル）

## 公開範囲について

全ページに `noindex,nofollow` を指定し、`robots.txt` で全パスを Disallow しています。
ただし **これは検索結果に出さないための設定で、アクセス制限ではありません。**
URLを知っていれば誰でも閲覧できます。社外への共有はお控えください。
